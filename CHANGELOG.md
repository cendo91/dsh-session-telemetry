# Changelog

## 1.0.0

First public release.

- Detailed telemetry strip below the composer: current-session turns, steps,
  model/tool time, first-token latency, output speed, token buckets, cache-hit
  rate, context occupancy, and system/tools/messages composition.
- Replaces the shipped `activity` and `usage` pills and hides the shipped
  context ring while active.
- Responsive width with container-query stacking.
- Five-color accent palette and English/Chinese UI.
- No new projections, tools, prompt sections, model inputs, network requests,
  or session events.
